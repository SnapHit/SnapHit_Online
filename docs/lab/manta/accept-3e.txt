Bots only (your manta parked out of the water), ten bots on the one brain of

summed exactly (first places and ties add; top-three counts are recovered
from each chunk's share, which is exact at 75 slots).

  node accept.mjs 4h <from> <to> <cost>     test 4, five timid against five bully
  node accept.mjs 3 <from> <to>             test 3, upsets and the top train
  node accept.mjs crashes <from> <to>       crashes per bot per five minutes
  half.mjs <from> <to>                      the longest train's share (below)

The share: every simulated second, the longest living train's mantas (its
leader and followers) over every manta in the water (living trains and every
living wild manta, debris included); each seed's worst moment is kept. The
script is short enough to give here in full:

  const s = createSim({ seed, params: <the same mapping as accept.mjs> });
  s.you.dead = 1e9; s.you.followers.length = 0;
  for (let i = 0; i < 18000; i++) { s.step(); s.events.length = 0; if (i % 60) continue;
    let all = 0, big = 0;
    for (const t of s.rivals) { if (t.dead > 0) continue; const n = 1 + t.followers.length; all += n; big = Math.max(big, n); }
    for (const w of s.wild) if (w && w.alive) all++;
    worst = Math.max(worst, big / all); }

A flag is raised where either half takes first place two times in three or
more. Nothing here changes a game value.
